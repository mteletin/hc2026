# cpm_1998/disk1

HC2000 CP/M 56K software from 1996-1998: 82 Turbo Pascal sources, the FM music programs with their .aud, .grp and .prg
files, and the tools of that disk. Imported byte for byte, as host files rather than a disk image, from
github.com/mteletin/hc2000, folder `cpm_1998/disk1`, commit 9780df89612c3fa0706fa2ffa9f724c1fa2c4cec, under the MIT
licence in `LICENSE` next to this file.

The disk inventory (`disks/inventory.json`) lists every file here with its hash, and the prepared workstation drives
lay them out in folders.

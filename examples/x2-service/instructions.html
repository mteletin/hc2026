X2 VGA: explicit guest command service

This in-house tape loads a BASIC-callable example and a bounded, main-owned X2 command service. It is not a console hook: normal BASIC and CP/M output remain on the ULA. It does not install into BIOS or reserve common RAM.

Start and load

  1. Start a new full-X5 machine with the X2 command VGA accelerator enabled. The equivalent flags are --memory paged --m-view --side-z80 16 --driver-z80 0 --x2-vga. The fresh card must be main-owned, with no other program using its ports.
  2. In BASIC enter CLEAR 32767, insert the supplied X2VGA.tap, enter LOAD "" CODE and press PLAY. Wait for the BASIC editor to return; eject the clean tape.
  3. Enter PRINT USR 32768. BASIC returns 0 on the ULA when the palette, Clear and Present commands complete. Then choose X2 VGA in the machine's display selector to see the white surface. Any nonzero result is a refusal or timeout, not success.

These are Spectrum BASIC tokens, not pasted keyword letters. CLEAR is X at the K cursor; LOAD is J; quotes are SYMBOL SHIFT+P; CODE is extended mode then I; PRINT is P; USR is extended mode then L. This uses ordinary tape loading, not a host memory edit.

Calling from guest code

After loading, CALL 0x8003 with HL pointing to a complete 1–32 byte X2 command frame and D holding its length. A=0 means the card completed; A=1–4 is an admission refusal, A=FE is a bounded timeout or non-Done terminal, A=FF an invalid length. AF, BC, DE and HL are clobbered. The caller owns and must preserve the code at 0x8000, its frame, stack and RAM placement; serialize access to the card. Do not use this entry when an exclusive driver Z80 owns the data port. The source x2.service.asm is supplied so a program can assemble the service into its own verified placement.

Version 1 frames

A frame begins with eight bytes: version 1, opcode, payload length, reserved zero, then a four-byte little-endian tag. The total is eight plus the payload length. Coordinates, sizes and scroll distance below are unsigned little-endian 16-bit values; colour and palette components are bytes. Use valid rectangles inside the 320×240 surface; invalid commands are refused.

  • 1 Clear: colour (1 byte).
  • 2 FillRectangle: x, y, width, height, colour (9 bytes).
  • 3 CopyRectangle: destination x, y, width, height, source x, y (12 bytes).
  • 4 SetPalette: index, red, green, blue (4 bytes).
  • 5 Present: empty payload. Presents the accumulated back plane at the next video boundary.
  • 6 DrawGlyph: x, y, foreground, background, four little-endian bytes of glyph rows (10 bytes).
  • 7 ScrollUp: x, y, width, height, scroll distance, background (11 bytes).

The complete Clear example with tag 1 and colour 7 is 01 01 01 00 01 00 00 00 07; Present with tag 2 is 01 05 00 00 02 00 00 00. A failed or timed-out request may still be active: quiesce or reset the machine before reusing the service. This example does not prove a BIOS/common-RAM fit or install a resident driver.
